# Frontend Development Projects

A collection of portfolio-ready frontend projects focused on responsive UI, JavaScript interactions, accessibility, and API-driven interfaces.

## Projects

### 01 — Responsive Product Landing Page
A responsive e-commerce landing page with reusable product cards, mobile navigation, semantic HTML, and polished CSS layouts.

**Stack:** HTML, CSS, JavaScript

### 02 — Weather Dashboard
A responsive weather dashboard that demonstrates API integration, search, loading/error states, and dynamic UI updates.

**Stack:** HTML, CSS, JavaScript, REST API

### 03 — Task Management Dashboard
A productivity dashboard with task creation, filtering, status changes, local persistence, and responsive layouts.

**Stack:** HTML, CSS, JavaScript, LocalStorage

## Goal

These projects are designed to demonstrate practical frontend development skills rather than just static pages: responsive design, component-like UI patterns, state management, accessibility, and clean JavaScript.
