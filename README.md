# Mothelahari — Portfolio

A clean, responsive personal portfolio built with plain HTML, CSS, and JavaScript.

## Structure

- `index.html` — portfolio content and structure
- `styles.css` — responsive visual system
- `script.js` — small navigation/header interactions

## Run locally

Open `index.html` in a browser, or serve the folder with any static HTTP server.

## Deploy

This repository is ready for GitHub Pages. In GitHub, open **Settings → Pages**, select the `main` branch as the deployment source, and save.
